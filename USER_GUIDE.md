## Getting Started

### Step 1: Sign In with Pi Network
1. Open Godly Musical Songs
2. You'll see the login screen

- 📊 Trending songs worldwide
- 🌍 Language selector (top right)

1. Click the language dropdown (top right)
2. Select your preferred language (15 languages available)
3. Content automatically translates
4. Your choice is saved! 🎉

## How to Use Each Feature

### Using Artists Search
```
1. Click "Artists Search" on dashboard
2. Type artist name, genre, or keywords
3. Browse results
4. Click on artist to view profile
5. Click "View Profile" for more info
6. Send collaboration request or follow
```

### Uploading Your Music
```
1. Click "Upload Songs"
2. Enter song title
3. Enter your name
4. Select genre
5. Add release year
6. Write description
7. Upload audio file (MP3, WAV, FLAC)
8. Upload cover art image
9. Click "Upload Song"
10. Wait 24-48 hours for global availability
```

### Finding Studios
```
1. Go to "Studios" section
2. Use search to find by location
3. Read ratings and reviews
4. View equipment and pricing
5. Click "Book Now" to schedule
6. Confirm booking details
7. Process payment in Pi
```

### Shopping for Music
```
1. Browse "Songs & Playlists"
2. Find songs you like
3. Click play to preview
4. Go to "Music Cart"
5. Add items to cart
6. Adjust quantities
7. Review order
8. Pay with Pi Network
9. Download your music
```

### Joining Groups
```
1. Go to "Groups & Churches"
2. Browse available groups
3. Click group name to view details
4. Read group description
5. Click "Join" button
6. Confirm membership
7. Start participating!
```

## Common Tasks

### Upload Your First Song
**Time needed:** 5 minutes
```
1. Create account and sign in
2. Go to "Upload Songs"
3. Fill in all fields:
   - Title
   - Artist name
   - Genre (Gospel, Worship, etc.)
   - Release year
   - Description
4. Upload audio file
5. Upload cover image
6. Click "Upload"
7. Done! Available globally in 24-48 hours
```

### Connect with an Artist
**Time needed:** 2 minutes
```
1. Go to "Artists Search"
2. Find the artist
3. Click "View Profile"
4. Click "Send Message" or "Collaborate"
5. Type your message
6. Send
7. Wait for their response
```

### Subscribe to Newsletter
**Time needed:** 1 minute
```
1. Go to "Newsletters"
2. Browse available newsletters
3. Click "Subscribe"
4. Confirm subscription
5. Start receiving updates
```

### Make a Purchase with Pi
**Time needed:** 3 minutes
```
1. Browse music in "Songs & Playlists"
2. Click play to listen
3. Go to "Music Cart"
4. Review items
5. Click "Pay with Pi"
6. Confirm transaction
7. Receive download link
8. Enjoy your music!
```

